# Lakki Hamburger Shop Company

A modern, premium burger shop landing page.

Original design from CodePen: [https://codepen.io/ssebfv/pen/NPbMwYe](https://codepen.io/ssebfv/pen/NPbMwYe)

## Features

- **Responsive Design** - Mobile-friendly layout
- **Modern UI** - Luxury aesthetic with gold accents
- **Smooth Animations** - Hover effects and transitions
- **Optimized Images** - External image sources
- **SEO Ready** - Proper semantic HTML

## Project Structure

```
lakki-burgers/
├── src/
│   └── index.html          # Source HTML with embedded CSS
├── dist/
│   └── index.html          # Distribution version
├── README.md
└── LICENSE.txt
```

## Getting Started

Open `src/index.html` or `dist/index.html` in your browser to view the website.
